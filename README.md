# senegal-quiz-ghs-dohr
## Pythagoras City (`pythagoras-city.html`)

3D-Open-World-Lernspiel (Third-Person-Ansicht, three.js) für Mathe (Klasse 8/9) zum Satz des Pythagoras. Man startet zu Fuß und erspielt sich im Autohaus
Fahrrad, Motorroller, Kleinwagen, Pickup und Sportwagen (Preis + Mindest-Rang). Bei sechs Auftraggebern (Feuerwache, Baustelle, Elektromarkt, Bauamt, Park-Kurier, Taxi-Zentrale)
Pythagoras-Aufgaben lösen und anschließend pünktlich ausliefern. Einfach die Datei im Browser öffnen –
keine Installation nötig (Internetverbindung für three.js nötig). Steuerung: WASD/Pfeiltasten, E für Aufträge, V für die Kamera, G für die Garage, H für die Theorie. Auf Tablets erscheinen Touch-Tasten.
